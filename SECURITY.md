# Security Policy

Demanity protects people's political privacy, so security reports are our highest priority.

## Reporting a vulnerability
- **Do not open a public issue.** Report privately through **GitHub private vulnerability reporting** on this repository.
  > TODO (before first public commit): enable private reporting and add a security contact address.
- **What we commit to:**
  - acknowledging your report within 72 hours;
  - agreeing on a coordinated disclosure timeline with you;
  - crediting you publicly, if you want credit.

## In scope (highest priority)
- Linking a ballot to an account
- Reading the identity vault, or linking vault records to activity records
- Bypassing the one-account-per-person rule or the one-ballot-per-poll rule
- Tampering with tallies or scores
- Prompt injection against the fact-check AI

## Out of scope
- Social engineering of staff
- Denial-of-service testing against production
