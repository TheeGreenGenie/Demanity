# Demanity

**Democracy + Humanity.** Demanity is a not-for-profit, open-source **government accountability** platform for verified US citizens aged 18 and over.

- **Track what government does.** Every new bill, executive order, regulation and court ruling at the federal level and in the states covered.
- **Hold leaders to their own word.** Every sitting federal and state official has a trust page. Crowd-reviewed, sourced citations on that page compare the leader's actions to their declared stances.
- **Measure opinion honestly.** One verified person casts one unlinkable ballot per poll.
- **Talk it through.** Forums by topic, location and bill. Users control their own feed.
- **Remember we're human.** A section dedicated to the good people do for each other.

> **Status:** pre-build. No application code exists yet.
>
> - **Design:** documented below.
> - **Public roadmap:** see [docs/VISION.md → Development roadmap](docs/VISION.md#development-roadmap-public-overview).
> - **Task tracking:** the detailed build list is kept internal because it tracks security-sensitive work in progress. Open tasks are published as GitHub Issues once they are safe to discuss publicly.

## MVP scope
- **Government levels:** federal, plus California, Texas, Florida, New York and Pennsylvania, the five most populous states ([US Census Bureau population estimates](https://www.census.gov/data/tables/time-series/demo/popest/2020s-state-total.html)).
- **Platforms:** an Expo (React Native) app for iOS, Android and web.
